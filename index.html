1 project

HTML CSS JavaScript

Typing Speed Test

A timed typing test with live WPM and accuracy, colored feedback per letter, and a best score saved for each duration.

How it's built

HTML5

Semantic structure and a hidden text input that captures typing, so it works on phones too. ARIA labels for accessibility.

CSS3

CSS variables, Grid and Flexbox, a blinking cursor and result animations, media queries, and reduced-motion support.

JavaScript

Builds the text in the DOM, reads every keystroke from the input event, times each round with setInterval and performance.now(), calculates WPM and accuracy, and saves best scores in localStorage.

Aa

Google Fonts

Inter and Space Grotesk, plus the system monospace font for the typing text.

Git · GitHub · Vercel

Version control with Git, hosted on GitHub and deployed on Vercel, which redeploys automatically on every push.
